# 기능 목록

## 1. 입력 처리

-   [ ] [예상 방문 날짜] 입력받기
    -   `Console.readLineAsync()`를 활용하여 숫자로 입력받는다.
    -   예시: `3`
-   [ ] [주문할 메뉴와 개수] 입력받기
    -   `Console.readLineAsync()`를 활용하여 [메뉴-개수]형식으로 입력받는다.
    -   예시: `티본스테이크-1,바비큐립-1,초코케이크-2`

## 2. 입력 파싱 및 검증

-   [ ] [예상 방문 날짜] 파싱 및 검증
    -   숫자인지 확인한다.
    -   1~31 범위인지 확인한다.
-   [ ] [주문할 메뉴와 개수] 파싱 및 검증
    -   [","]를 기준으로 분리하여 [메뉴-개수, 메뉴-개수]형식으로 변환한다.
    -   실제 메뉴에 있는 메뉴인지 확인한다.
    -   총 메뉴 개수가 20개를 초과하진 않는지 확인한다.
    -   음료만 주문하진 않았는지 확인한다.

## 3. 도메인 로직

-   [ ] Receipt class 구현

    -   1~31일 중 날짜를 상태로 가진다.
    -   `[{메뉴명 : 개수}, {메뉴명 : 개수}]` 형태의 주문한 메뉴 상태를 가진다.
    -   총 주문 금액을 상태로 가진다.
    -   총혜택 금액을 상태로 가진다.

    -   메뉴를 순회해 총 주문 금액을 반환하는 메서드
    -   총 금액이 12만원 이상이어서 샴페인을 증정할지 결정하는 메서드
    -   날짜를 기반으로 월 ~ 목에 해당하는지, 해당한다면 디저트 메뉴 1개당 2023원을 혜택 상태에 추가 및 얼마 할인 됐는지 반환하는 메서드
    -   날짜를 기반으로 금 ~ 일에 해당하는지, 해당한다면 메인 메뉴 1개당 2023원을 혜택 상태에 추가 및 얼마 할인 됐는지 반환하는 메서드
        날짜를 기반으로 별이 있는 날짜인지, 해당한다면 혜택 상태에 1000원 할인 추가 및 얼마 할인 됐는지 반환하는 메서드
    -   총 혜택 금액 상태를 기반으로 배지를 반환하는 메서드

## 4. 출력 처리

-   [ ] [이벤트 혜택 미리 보기] 출력

    -   `Console.print()`를 활용하여 요구된 형식으로 출력한다.
    -   형식:

    ```
    <주문 메뉴>
    티본스테이크 1개
    바비큐립 1개
    초코케이크 2개
    제로콜라 1개

    <할인 전 총주문 금액>
    142,000원

    <증정 메뉴>
    샴페인 1개

    <혜택 내역>
    크리스마스 디데이 할인: -1,200원
    평일 할인: -4,046원
    특별 할인: -1,000원
    증정 이벤트: -25,000원

    <총혜택 금액>
    -31,246원

    <할인 후 예상 결제 금액>
    135,754원

    <12월 이벤트 배지>
    산타
    ```

## 5. 예외 처리

-   [ ] [방문할 날짜] 예외 처리
    -   [1 이상 31 이하의 숫자가 아닌] 경우 `[ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요.` 출력 후 재입력
-   [ ] [주문 메뉴] 예외 처리
    -   [메뉴판에 없는 메뉴를 입력하는] 경우 `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.` 출력 후 재입력
    -   [메뉴의 개수가 1 이상의 숫자가 아닌] 경우 `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.` 출력 후 재입력
    -   [메뉴 형식이 예시와 다른] 경우 `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.` 출력 후 재입력
    -   [중복 메뉴를 입력한] 경우 `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.` 출력 후 재입력
